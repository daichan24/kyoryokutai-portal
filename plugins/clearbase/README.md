# ClearBase plugin

ChatGPT Work / Codexから、ClearBaseへログインした本人の予定・休み・タスク・ミッション・プロジェクト・メモを操作するためのプラグインです。

- MCP URL: `https://kyoryokutai-backend.onrender.com/mcp`
- 認証: OAuth 2.1 Authorization Code + PKCE
- データ範囲: 接続した本人のみ
- 管理操作: 非対応
- 課金処理: なし

開発者モードでの接続試験後、正式公開する場合はOpenAI Platformのプラグイン審査へ提出します。
